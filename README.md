## 🚀 Ejecutar en local

Necesitas Node.js 22.23.4 o superior y [pnpm](https://pnpm.io).

```sh
pnpm install
pnpm dev
```

Cada proyecto de la carpeta `demos/` es independiente y mantiene las versiones de React y bibliotecas usadas en su clase.
